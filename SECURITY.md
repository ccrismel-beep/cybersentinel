# Politique de sécurité

## Signaler une vulnérabilité

Ne publiez pas de vulnérabilité exploitable dans une issue publique.

Utilisez la fonction **Security advisories** du dépôt GitHub pour envoyer un signalement privé :

1. ouvrez l’onglet **Security** du dépôt ;
2. choisissez **Report a vulnerability** ;
3. décrivez le problème, son impact et les étapes minimales pour le reproduire.

Évitez d’inclure des mots de passe, fichiers personnels, jetons ou autres données sensibles. Une réponse sera apportée dès que possible après examen du signalement.

## Périmètre

La branche principale et la dernière version publiée sont prises en charge. Les résultats produits par LinkCheck et l’analyseur de mots de passe sont indicatifs et ne constituent pas une garantie de sécurité.
