# Contribuer à CyberSentinel

Merci de contribuer à CyberSentinel.

## Avant de commencer

- Ouvrez une issue pour décrire une évolution importante.
- Ne joignez jamais de données personnelles, mots de passe réels ou fichiers confidentiels.
- Préservez le fonctionnement local des outils : aucune télémétrie et aucun envoi automatique de données.
- Toute nouvelle ressource externe doit indiquer clairement quelles informations peuvent quitter l’appareil.

## Développement

```bash
npm install
npm run dev
```

Avant de proposer un changement :

```bash
npm run lint
npm run build
```

Décrivez le comportement modifié et les vérifications effectuées dans la pull request.
